## Why

“帮帮帮”是一个面向社区老年群体与青年志愿者的互助服务微信小程序平台。当前需要将 `/docs/需求文档.txt` 与 `/docs/ui/` 下的 40 余张原型稿完整落地为可运行的前端项目。通过 Uni-app (Vue 3 + TypeScript) 搭建适老化互助闭环，初期采用完整本地 Mock 与 Storage 状态持久化方案，确保在无后端依赖的情况下完整复现所有界面视觉与端到端业务流程。

## What Changes

- **工程脚手架与适老化基座**：搭建基于 Uni-app + Vue 3 + TypeScript + Pinia 的工程结构，严格 1:1 还原 `/docs/ui/` 原型稿视觉规范（大字体、高对比度配色、宽大点击热区、全局字体大小动态缩放）。
- **互助订单体系**：实现老人端一键求助/分类下单（帮抢鸡蛋、一起购物、陪伴就医等 8 类服务），志愿年轻端任务抢单/接单，以及订单状态机（待接单、进行中、已完成、已取消、兑换订单物流追踪）。
- **即时通讯与通讯录**：实现联系人通讯录（A-Z 首字母索引、新增联系人）与即时私信聊天（支持文字、照片/拍照、语音条、名片、文件发送及右上角更多信息）。
- **广场社区与发帖**：实现互助动态发布、人名搜贴、点赞评论、动态列表与一键加好友。
- **积分商城与物流**：实现志愿积分/金币兑换生活物资（鸡蛋、纸巾等）、购物车批量兑换、金币提现、以及兑换订单物流节点全流程追踪（已发货、转站中、已到达、取件码）。
- **个人中心与适老配置**：实现个人资料管理、实名/身份认证（@学生、@村干部等身份标签）、地址管理、常见问题以及全局字体大小滑块无级调节。
- **本地 Mock 与存储持久化**：建立服务防腐层（Service Layer）与预置种子数据，通过 `uni.setStorageSync` 实现完全离线可交互闭环演示。

## Capabilities

### New Capabilities
- `elderly-ui-foundation`: 适老化设计规范、全局动态字体缩放、五大 Tab 导航及适老通用组件库。
- `order-service`: 互助需求下单、志愿者接单、订单生命周期管理及服务评价。
- `im-messaging`: 即时通讯会话、多媒体消息收发及 A-Z 拼音索引通讯录。
- `square-community`: 社区广场动态发布、人名搜索贴文、评论互动与加好友。
- `points-mall`: 积分/金币商城、物资兑换、购物车结算、运单物流追踪及金币提现。
- `user-profile`: 用户个人资料、实名身份认证、常用地址及常见问题。

## Impact

- **新增代码与工程**：创建全新的 Uni-app 小程序项目目录结构、页面、样式与组件。
- **依赖库**：`vue@3`, `pinia`, `@dcloudio/uni-app`, `typescript`, `@types/wechat-miniprogram` 等。
- **静态资源**：引入 `/docs/ui/` 中提取的原型图标、头像及示范商品图。
- **API 与数据层**：建立完全离线的 Pinia Store 与 Storage 持久化防腐层，后续可直接平滑切换到网络请求。
