# 帮帮帮小程序功能实现现状与待办梳理

> 更新时间：2026-10-26  
> 适用范围：当前 `src/` 代码与 `dist/build/mp-weixin` 构建产物  
> 目标：在不改动现有 UI 的前提下，明确哪些功能已经真实可用、哪些是本地 Mock / 假数据、哪些尚未实现，作为后续接入后端和真实业务能力的任务清单。

## 0. 结论摘要

当前项目是一个 **高保真前端原型 + 本地 Mock 数据** 的微信小程序：

- 页面、路由、视觉、适老化字号、基础交互已经比较完整。
- 所有业务数据来自 `src/mock/seeds.ts`，并写入 `uni.setStorageSync`，没有后端接口。
- 已真实调用微信能力的地方主要是：地图选点、录音、音频播放、图片预览、本地存储、权限申请。
- 尚未接入：账号体系、短信、实名认证、实时聊天、文件/图片上传、订单双向确认、支付、物流、订阅消息、内容审核、隐私协议。
- 因此当前适合做演示和 UI 验收，但还不能支撑真实业务闭环。

建议后续按以下顺序推进：

1. **P0：基础设施 + 登录/注册 + 实名认证 + 订单闭环 + 聊天实时化 + 内容审核/隐私合规**
2. **P1：广场图片/评论、兑换库存/物流、提现、头像/地址持久化、客服/通知**
3. **P2：搜索分页、分享、数据统计、监控与无障碍优化**

## 2. 全局技术现状

### 2.1 技术栈

- Uni-app + Vue 3 + TypeScript + Pinia
- 微信小程序构建目录：`dist/build/mp-weixin`
- 开发工具指向：`dist/dev/mp-weixin`
- 当前生产构建包体约 **1.15 MB**，开发构建约 **1.44 MB**

### 2.3 当前没有接入的能力

代码中未发现以下调用：

- `uni.request` / `wx.request`：没有后端请求
- `uni.login` / `wx.login`：没有微信登录
- `getPhoneNumber`：没有手机号快捷绑定
- `uni.uploadFile`：没有文件/图片上传
- `uni.connectSocket`：没有 WebSocket
- `uni.requestPayment`：没有支付
- `requestSubscribeMessage`：没有订阅消息
- `chooseImage` / `chooseMedia`：仅头像修改使用 `chooseMedia`，其他图片/音频上传未接入
- `getLocation`：没有主动定位，只有 `chooseLocation`
- `onShareAppMessage` / `onShareTimeline`：没有分享配置
- 隐私协议、用户协议、内容审核：没有对应页面或逻辑

### 2.4 已真实接入的微信能力

| 能力 | 使用位置 | 说明 |
|---|---|---|
| `uni.chooseLocation` | 下单页 | 选择上门地点，含权限失败提示 |
| `uni.getRecorderManager` | 私信/线上咨询 | 真实录音 |
| `uni.createInnerAudioContext` | 私信/线上咨询 | 真实播放本地录音 |
| `uni.previewImage` | 私信 | 预览聊天图片 |
| `uni.getSetting` / `uni.authorize` / `uni.openSetting` | 录音、地图 | 权限申请与设置引导 |
| `uni.setStorageSync` / `getStorageSync` | 各 Store | 本地持久化 |
| `uni.showModal` / `showActionSheet` / `showToast` | 各页面 | 交互反馈 |

### 2.5 主要风险

1. **没有服务端**：清缓存或换设备后数据丢失，无法多端同步。
2. **登录态不可信**：只依赖本地 `bbb_user.isLoggedIn`，没有 token 校验。
3. **语音文件会失效**：聊天语音保存的是 `tempFilePath`，小程序重启后可能无法播放。
4. **订单无并发控制**：接单是本地直接改状态，没有服务端抢占/幂等。
5. **无内容审核**：帖子、聊天、图片、语音都没有审核和举报能力。
6. **无隐私合规**：实名、手机号、地址等敏感信息没有加密、授权说明和隐私协议。
7. **无库存/支付/物流**：兑换和提现都是本地扣积分，没有真实交易能力。
8. **无消息触达**：接单、取消、兑换发货等状态变化不会通知对方。

## 5. 建议实施顺序

## 8. 验收建议

后续每完成一个模块，建议按以下路径做一次真机验收：

1. **登录/注册**：微信登录 → 绑定手机号 → 退出 → 重新登录。
2. **实名认证**：提交实名 → 人脸核身 → 状态回显。
3. **订单闭环**：老人下单 → 帮手接单确认 → 到达确认 → 完成 → 双方确认 → 评价。
4. **聊天**：文字/图片/语音发送 → 对方实时收到 → 已读/未读 → 断网重发。
5. **兑换**：加购 → 库存校验 → 兑换 → 扣金币 → 物流 → 收货。
6. **提现**：实名校验 → 绑定账户 → 提现申请 → 到账/失败。
7. **个人资料**：头像上传 → 资料保存 → 多端同步。
8. **真机专项**：麦克风权限、录音播放、键盘顶起、地图选点、弱网/断网。
